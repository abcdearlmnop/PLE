# Our Holy Rosary

Our family Rosary with petitions and intentions, as a phone app.

Open it on iPhone in Safari, tap Share, then **Add to Home Screen**.

## Updating the prayers
1. Edit `index.html`.
2. In `sw.js`, change `rosary-v1` to `rosary-v2` (then v3, and so on).
3. Commit. Phones pick up the change the next time the app is opened online.
